# 服务器监控技能

用于采集和判断服务器基础资源状态。

## 检查项

- CPU：负载、核心数、CPU 使用趋势。
- 内存：总量、已用、可用、Swap。
- 磁盘：容量、inode、异常挂载点。
- 进程：高 CPU/内存进程、异常进程。
- 网络：监听端口、基础连通性。

## 推荐命令

```bash
uptime
top -bn1
free -m
df -h
df -ih
ps aux --sort=-%cpu
ps aux --sort=-%mem
ss -tlnp
```

## 判断标准

- CPU 使用率长期高于 80% 需要关注，高于 95% 需要告警。
- 内存使用率高于 85% 需要关注，高于 95% 需要告警。
- 磁盘或 inode 高于 80% 需要关注，高于 90% 需要告警。
- 出现大量僵尸进程、异常端口或关键服务缺失时需要提示风险。
